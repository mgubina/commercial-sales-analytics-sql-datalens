# Коммерческий аудит продаж: Маржинальность, кумулятивная динамика и ранжирование каналов сбыта

## 📌 Бизнес-контекст и задачи
Компания ведет коммерческую деятельность по четырем ключевым направлениям сбыта: **Экспорт**, **Оптовые поставки**, **Электронная коммерция (E-commerce)** и **Розничные продажи**. Для оценки чистой финансовой эффективности каждого канала и выявления точек роста потребовалось провести комплексный коммерческий аудит.

**Ключевые цели проекта:**
1. Консолидировать разрозненные транзакционные логи доходов и расходов в единую аналитическую витрину.
2. Перенести расчет сложной финансовой динамики (ранжирование каналов, нарастающий итог маржи, цепные приросты) на уровень базы данных с помощью оконных функций PostgreSQL.
3. Развернуть интерактивный дашборд в **Yandex DataLens** для верхнеуровневого мониторинга ключевых показателей эффективности (KPI) топ-менеджментом.

---

## 🛠 Архитектура решения и технический стек

* **СУБД:** PostgreSQL (среда разработки DBeaver).
* **Трансформация данных (ETL):** Пошаговая цепочка SQL-представлений (`Views`) для поэтапной агрегации данных по месяцам, исключающая искажение сумм при объединении фактов выручки и себестоимости.
* **Аналитический SQL:** Оконные функции (`DENSE_RANK`, `SUM OVER`, `LAG`) для расчета помесячных рейтингов направлений, кумулятивной маржи и помесячного прироста.
* **BI-платформа:** Yandex DataLens (построение KPI-карточек, комбинированных диаграмм, матриц с условным форматированием и вычисляемых показателей).

---

## 📐 Логика обработки данных

Обработка и подготовка данных в PostgreSQL реализована в 3 последовательных этапа:

1. **Агрегация выручки:** Помесячное схлопывание всех коммерческих поступлений в разрезе направлений бизнеса.
2. **Агрегация себестоимости:** Помесячная сумма затрат на производство и логистику по каждому направлению.
3. **Формирование аналитической витрины:** Объединение показателей выручки и себестоимости с обогащением расчетными метриками:
   * **Маржа:** Вычисление абсолютной чистой прибыли направления.
   * **Рентабельность:** Расчет процентного соотношения маржи к выручке.
   * **Ранжирование (`DENSE_RANK`):** Ежемесячное присвоение мест направлениям на основе их маржинальности.
   * **Нарастающий итог (`SUM OVER`):** Кумулятивное накопление маржи с начала года для оценки реального масштаба каждого канала.
   * **Сдвиг во времени (`LAG`):** Сравнение показателей текущего месяца с предыдущим для выявления динамики и сезонных трендов.

## 📊 Ключевые бизнес-инсайты

На основе разработанного дашборда сформированы следующие выводы для коммерческого департамента:

* **Общие финансовые результаты:** Годовая выручка предприятия составила **405 млн ₽**, чистая маржа — **62 млн ₽** при средней рентабельности бизнеса **15%**.
* **Структура прибыльности (Объем vs Маржинальность):** 
  * Канал **Розничные продажи** демонстрирует наибольшую норму рентабельности (до **38%** в пиковые месяцы), однако имеет ограниченную емкость рынка.
  * Канал **Экспорт** при умеренной маржинальности (около **12%**) за счет эффекта масштаба и объемов оборачиваемости стал главным генератором чистой прибыли, принеся **20.9 млн ₽** кумулятивной маржи к концу года.
* **Выявление точек риска (Анализ LAG):** Метрика сдвига во времени позволила обнаружить локальный провал маржинальности в направлении **E-commerce** в летний период (июнь–июль), когда затраты вплотную приблизились к уровню выручки. Это дает основание для пересмотра структуры маркетинговых расходов в несезон.
